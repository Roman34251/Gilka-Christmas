# Гілка свята

React-магазин із серверним HTML каталогу, кошиком у браузері та Sanity Studio. Для запуску використовуйте Node.js 24.

## Локальний перегляд

У корені проєкту виконайте `npm ci` та `npm start`. Відкрийте http://127.0.0.1:4173. Без налаштувань Sanity сервер читає чотири демонстраційні товари з локальної SQLite. Кнопка копіювання списку працює на localhost або через HTTPS.

## Підключення Sanity

Проєкт `fcl0yp5j` і dataset `production` уже записані в локальних файлах `.env` магазину та Studio. Сервер автоматично читає `.env` під час запуску. Sanity Studio запускається командою `npm run dev` у каталозі `studio`. Увійдіть акаунтом, якому належить проєкт. Для редагування через локальну Studio може знадобитися дозволити origin `http://localhost:3333` у налаштуваннях API проєкту.

1. У своєму акаунті Sanity створіть проєкт і публічний dataset `production`. Додайте `http://localhost:3333` до дозволених CORS origins з credentials для локальної Studio.
2. У каталозі `studio` виконайте `npm ci`. Задайте `$env:SANITY_STUDIO_PROJECT_ID='ваш-id'` у PowerShell, потім запустіть `npm run dev`. Для іншої назви dataset задайте `SANITY_STUDIO_DATASET`. Для публікації адмінпанелі є команда `npm run deploy`.
3. У Studio відкрийте «Товар». Вкажіть назву, категорію, ціну, опис і фото. Порядок фото визначає галерею, перше фото є обкладинкою. Опублікуйте запис.
4. В іншому терміналі в корені магазину задайте `$env:SANITY_PROJECT_ID='ваш-id'` і запустіть `npm start`. Назву dataset можна змінити через `SANITY_DATASET`. Після публікації змін у CMS оновіть сторінку магазину. Кнопки фільтрів формуються за категоріями опублікованих товарів.
5. Задайте `ORDER_EMAIL` перед запуском, щоб покупець міг відкрити поштову програму з підготовленим списком. Покупець натискає «Надіслати» у своїй пошті. Адреса продавця публічна. Магазин не зберігає персональних даних покупців на сервері.

Для запуску на сервері задайте `PORT` і за потреби `HOST`, налаштуйте HTTPS. Поточний етап охоплює вітрину й кошик. Підключення домену, фактичні умови доставки, оплата та імпорт фіда — окремі кроки перед стартом продажів.
