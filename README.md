# Гілка свята

React-магазин із серверним формуванням каталогу в Cloudflare Workers і товарами в Sanity. Node.js 24 потрібен для локальної збірки. На хостингу код виконує Cloudflare Workers.

## Публікація через GitHub і Cloudflare

Оновіть файли в репозиторії GitHub, включно з package.json, package-lock.json, build.mjs, server.mjs і wrangler.jsonc. Конфігурація Wrangler має бути в корені репозиторію, поруч із package.json.

На екрані Cloudflare Create an app для репозиторію Gilka-Christmas задайте такі значення.

| Поле | Значення |
|---|---|
| Project name | gilka-christmas |
| Root directory | корінь репозиторію, залишити стандартне значення |
| Build command | npm run build |
| Deploy command | npx wrangler deploy |
| Build variable NODE_VERSION | 24 |

Cloudflare встановить залежності, збере React і серверний код, потім опублікує Worker. Після успішного деплою скопіюйте фактичну адресу із панелі Cloudflare. Назва gilka-christmas збігається з полем name у wrangler.jsonc.

Файл wrangler.jsonc містить публічний ідентифікатор Sanity fcl0yp5j та dataset production. Токен для читання публічного каталогу не потрібен. Поле ORDER_EMAIL можна додати до vars у цьому файлі, щоб активувати надсилання списку через поштову програму покупця. Адреса продавця буде публічною.

## Локальна перевірка

У корені проєкту виконайте npm ci, потім npm start. Відкрийте http://localhost:4173. Команда запускає збірку і локальне середовище Cloudflare Workers. Локальний .env може перевизначити параметри Sanity. Файли .env та .dev.vars залишаються локальними.

Команда npm run build створює dist/worker.js і dist/assets. Збірка не потребує доступу до Sanity. Каталог завантажується під час запиту до сайту, тому оновлення товару через Publish видно після оновлення сторінки.

Для перевірки готовності до публікації виконайте npx wrangler deploy --dry-run. Команда npm run deploy збирає та публікує сайт із комп’ютера і потребує входу Cloudflare.

## Адмінпанель Sanity

Studio знаходиться в окремій папці studio. У ній є власні команди npm run dev та npm run deploy. Деплой Studio і деплой магазину виконуються окремо.

Обидві частини використовують проєкт fcl0yp5j та dataset production. У Studio відкрийте «Товар», заповніть назву, категорію, ціну, опис і фото та натисніть Publish. Порядок фото визначає галерею, перше фото є обкладинкою. Категорії формують фільтри магазину.

## Поведінка сервера

- Головна сторінка містить готовий HTML каталогу та React-код для взаємодії.
- /api/products повертає опубліковані товари.
- Фото, CSS і браузерний JavaScript роздаються через Cloudflare Static Assets.
- Збій Sanity повертає 503, а відсутній маршрут — 404.
- При налаштованому Sanity порожня база показує «Колекція готується».
- Демонстраційні товари використовуються лише за відсутнього SANITY_PROJECT_ID. Налаштований production-проєкт читає реальну базу.
- Кошик зберігається в браузері. Платіжний сервіс, приймання замовлень і імпорт фіда потребують окремого підключення.
