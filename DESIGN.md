# Гілка свята: дизайн і шлях покупця

## Візуальне рішення

Хвойний зелений #203e33, теплий молочний #faf8f3, бордовий #8e3438. Playfair Display для великих заголовків, Manrope для інтерфейсу — обидва мають кирилицю. Фотографічний банер, чотири категорії, спокійні товарні картки. Рекомендації ui-ux-pro-max адаптовано до вебмагазину; React Native з шаблону скілу не застосовується до наявного React/Cloudflare проєкту.

## Сценарій

1. Головна: банер → каталог або одна з чотирьох категорій.
2. Каталог: пошук за назвою, сортування за ціною/назвою, наявність → товар.
3. Товар: фото, ціна, опис, характеристики, доставка → кількість → кошик.
4. Кошик: перевірка суми, зміна кількості, видалення → оформлення.
5. Оформлення: контакти → Нова пошта (відділення/поштомат) → післяплата або monobank → згода → підтвердження.
6. Сервер зберігає замовлення. Післяплата → підтвердження з номером. Онлайн → сторінка банку → повернення → перевірений статус.

Головна → Каталог → Товар → Кошик → Оформлення → [Післяплата: збережено | monobank: оплата → перевірка] → Підтвердження

Екрани: головна; весь каталог; 4 категорії; сторінка кожного товару; кошик; checkout; статус; доставка/оплата; повернення; приватність; контакти; 404.

## Порожні й помилкові стани

- Порожня категорія: пояснення й телефон, жодних вигаданих товарів у production.
- Пошук без результатів: підказка змінити запит.
- Порожній кошик: повернення до каталогу.
- Немає товару в наявності: додавання недоступне, оформлення блокується.
- Немає зв’язку: повідомлення й можливість повторити; повторний запит із тим самим ключем не дублює замовлення.
- Невизначена відповідь банку: збережене замовлення на перевірку, без повторного автоматичного списання.
- Реальне замовлення не підтверджується, доки база не зберегла запис.
- Оплата не вважається успішною на основі URL чи неперевіреного webhook.

## Менше зайвих кроків

Без акаунта, без реєстрації, один екран оформлення. Контакти магазину на кожній сторінці. Зрозуміло вказано, що доставка й комісія післяплати не включені у вартість товарів. Немає вигаданих відгуків, таймерів чи штучного дефіциту.

## Контент

Згенеровані атмосферні фотографії призначені для категорій. Фото реальних товарів надходять лише з Sanity. Демо-товари показуються тільки коли SANITY_PROJECT_ID відсутній і не можуть бути замовлені через сервер.
